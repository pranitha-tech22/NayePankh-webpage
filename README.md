NayePankh Foundation Internship Assignment

📖 Overview

This project is a responsive and informative website developed as part of the Technical Internship Assignment for NayePankh Foundation. The website aims to spread awareness about the organization's mission, vision, values, and social initiatives while providing an engaging and user-friendly experience for visitors.

The project demonstrates fundamental front-end web development skills using HTML, CSS, and JavaScript, with a focus on clean design, responsiveness, and accessibility.


🌟 Features

- Responsive design for mobile, tablet, and desktop devices
- Modern and clean user interface
- Navigation bar with smooth section navigation
- Home section introducing the organization
- About Us section
- Vision, Mission, and Values section
- Our Work section showcasing initiatives and impact
- Contact Us section
- Structured and readable content layout
- Simple and accessible design

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🎯 Project Objective

The objective of this project is to create a visually appealing and informative website that represents the mission and activities of NayePankh Foundation while demonstrating front-end web development skills including layout design, styling, responsiveness, and user interaction.

💙 About NayePankh Foundation

NayePankh Foundation is a non-profit organization dedicated to empowering individuals through education, social welfare initiatives, community development programs, and opportunities that help create a positive impact in society.

This website highlights the foundation's commitment to creating meaningful change and inspiring communities through collective efforts.
